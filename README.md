# What I Found Interesting
In this article, Violino discusses the ever-existing problem of burnout in the software engineering industry, but what really interested me in this article was his mention of AI's involvement in this issue. I've read many articles and reports about burnout in the past, but only now do I see AI mentioned as a problem to this humanly concept. Violino blames AI for pressuring software engineers into rushing to adopt new technologies without proper and slow training. This rush and sometimes "do it alone" process forces workers to put extra time and effort into understanding its use, which can lead to a "cognitive overload". Furthermore, AI creates a fear among software engineers about being replaced, which again encourages them to work harder and faster to keep up with these technologies. This phenomenon surprises me because it reflects a changing time of modern technologies and how new innovations affects things that have been prevalent for so long in the industry. It also creates this paradox where a tool that should simplify work would actually create more stress for its workers.
